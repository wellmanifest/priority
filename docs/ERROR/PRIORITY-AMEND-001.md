# PRIORITY-AMEND-001

Amendment that changes nothing, or malformed.

## Meaning

An amendment must set at least one of `rewriteIntent`, `setTier`, `setBase`, `retire`,
and any tier or duration it names must be valid.

## Cause

The document declares something the model does not permit; the surrounding text of the document usually shows which edit introduced it.

## Resolution

Set at least one of `REWRITE INTENT`, `SET TIER`, `SET BASE`, `RETIRE`, and check any tier or duration it names.
