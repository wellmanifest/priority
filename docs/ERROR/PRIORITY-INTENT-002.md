# PRIORITY-INTENT-002

Priority without evidence.

## Meaning

`because` is required.

A priority with no stated evidence is a preference. Preferences are legitimate but they
are not rankable against measurements, and mixing the two produces a list where the
loudest item wins. Point at something: a path and line, a finding code, an incident.

## Cause

The document declares something the model does not permit; the surrounding text of the document usually shows which edit introduced it.

## Resolution

Point at the evidence: a path and line, a finding code, an incident, a measurement.
