# PRIORITY-SIGNAL-002

Signal without a producer.

## Meaning

A signal must name the thing that produces its reading.

A rank is only as defensible as the measurement behind it. A signal with no producer
cannot be taken, so any rule depending on it either never fires or fires on a number
nobody can point at. Both outcomes turn a ranking back into an opinion, which is the
situation the document exists to end.

## Cause

A signal was sketched before the tool that would produce it existed, and the placeholder was never filled in.

## Resolution

Name the command, file, or service that yields the reading. If nothing can produce it yet, remove the signal and the rules that depend on it rather than leaving a rank resting on nothing.
