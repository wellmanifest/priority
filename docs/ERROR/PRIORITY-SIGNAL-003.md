# PRIORITY-SIGNAL-003

Condition on an undeclared signal.

## Meaning

A rule, amendment, or completion test refers to a signal the document never declares.

Declaring the signal is what forces the producer to be named, so this is not a naming
nicety: an undeclared signal is an unsourced one.

## Cause

The document declares something the model does not permit; the surrounding text of the document usually shows which edit introduced it.

## Resolution

Declare the signal with its producer, or point the condition at a signal that already exists.
