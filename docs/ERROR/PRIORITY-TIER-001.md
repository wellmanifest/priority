# PRIORITY-TIER-001

Unknown tier.

## Meaning

Tier must be `floor`, `standard`, or `opportunistic`. The set is closed because the
ordering guarantee depends on there being a fixed number of lexicographic bands.

## Cause

The document declares something the model does not permit; the surrounding text of the document usually shows which edit introduced it.

## Resolution

Use `floor`, `standard`, or `opportunistic`.
