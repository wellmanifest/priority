# PRIORITY-WEIGHT-001

Invalid base weight.

## Meaning

`base` must be a positive number. Zero or negative disables an item without removing it,
which hides the decision instead of recording it. Retire it with an amendment instead.

## Cause

The document declares something the model does not permit; the surrounding text of the document usually shows which edit introduced it.

## Resolution

Give a positive base. To stand an item down, retire it with an amendment so the decision is recorded.
